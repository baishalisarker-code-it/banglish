1. Smart Sentence Chunker
Regex pattern (?<=[।!?\n])\s+|(?<=[.!?])\s+ executes lookbehind segmentation. Preserves the sacred Bengali danda (।, U+0964), punctuation boundaries, and multiline clause structures without truncating discourse markers.
Mathematical & Algorithmic Logic

Core Computational Specifications

Rigorous formulations powering language identification, phonetic normalization, and sarcasm detection.

Script Identification

Evaluates Unicode codepoint bounds against Latin token densities and a curated 45+ token romanized Bengali lexicon:

S_{bn} = \{ c \in \text{text} \mid 0x0980 \le c \le 0x09FF \}
L_{roman} = \{ w \in \text{LatinWords} \mid w \in \text{ROMAN\_BN\_LEXICON} \}
\text{Script} = \begin{cases} \text{Bengali}, & |S_{bn}| \ge 2 \wedge |L_{roman}| = 0 \\ \text{Mixed}, & |S_{bn}| \ge 1 \wedge (|L_{roman}| \ge 1 \lor |Latin| \ge 1) \\ \text{Romanized}, & |L_{roman}| \ge 1 \wedge |S_{bn}| = 0 \\ \text{Latin}, & \text{otherwise} \end{cases}
U+0980..U+09FF O(N) Complexity Zero False Positives

Deadpan Sarcasm Dissonance

Detects irony and sarcasm by calculating cognitive dissonance between superlative praise markers and underlying negative clauses:

D_{sarcasm} = \mathbb{I}\Big[ \big(Praise_{marker} \wedge Polarity \in \{\text{Neg}, \text{Mixed}\}\big) \\ \lor \big(Contrast_{marker} \wedge Pos \ge 1 \wedge Neg \ge 1\big) \\ \lor \big(Praise_{marker} \wedge \text{"!"} \wedge Slang_{derogatory}\big) \Big]
Bilingual Valence Contrastive Syntax Slang Inversion

Bengali Cultural Idioms

Deterministic recognition of localized slang, colloquialisms, and idioms to provide contextual linguistic notes:

• 'ফালতু' (faltu) → Slang: Useless / Rubbish
• 'ঝামেলা' (jhamela) → Idiom: Headache / Trouble
• 'বাজে' (baje) → Colloquial: Inferior quality
• 'মাথা নষ্ট' (matha nosto) → Expression: Mind-blown

Production Stack

Technology & Tooling Matrix

Engineered for maximal performance, minimal footprint, and effortless cloud or offline deployment.

AI / ML & NLP Tier

  • Meta NLLB-200 (facebook/nllb-200-distilled-600M) Seq2Seq model with 200-language vocabulary.
  • PyTorch & Hugging Face Transformers: FP16 CUDA inference acceleration.
  • Indic NLP Library: Bengali orthographic normalizer & token boundaries.
  • SentencePiece BPE: Subword tokenization respecting Bengali conjunct characters.

Backend & Runtime

  • Zero-Dependency HTTP Server: Built on Python's native http.server.HTTPServer.
  • Modular Pipeline: Decoupled chunker, transliterator, and analyzer subsystems.
  • Multi-Tier Translation Matrix: Graceful degradation (NLLB-200 → Cloud Neural → Rule Matrix).
  • REST API: CORS-enabled JSON endpoints with sub-50ms dispatch.

Frontend & GitHub Pages

  • Glassmorphic Design System: Multi-layer backdrop blur and specular borders.
  • Static Client Mirror: Runs client-side NLP simulation on static GitHub Pages.
  • Zero External Framework Bloat: Pure HTML5, Vanilla CSS tokens, and ES6 JavaScript.
  • Live Telemetry Dashboard: Real-time clause breakdown and affective meters.

  -H "Content-Type: application/json" \
  -d '{
    "text": "বাহ! তোমার কাজটা খুব ভালো হয়েছে। এই কাজটা ফালতু হয়ে গেছে।",
    "direction": "auto"
  }'
import requests

url = "http://127.0.0.1:8080/api/translate"
payload = {
    "text": "আমি যাবো। কিন্তু ami bhalo achi na।",
    "direction": "auto"
}

response = requests.post(url, json=payload)
data = response.json()

print("Full Translation:", data["full_translation"])
print("Dominant Emotion:", data["summary"]["dominant_emotion"])
print("Sarcasm Detected:", data["summary"]["has_sarcasm"])

const result = await response.json();

Production Hosting

GitHub Pages & Local Setup

Host this showcase page on GitHub Pages with 1-click, or start the full local server with PyTorch GPU acceleration.

Option A: GitHub Pages Hosting

This repository is pre-configured for instant zero-configuration GitHub Pages hosting:

1. Push repo to GitHub:
   git push origin main

2. Open Repo Settings → Pages
3. Source: "Deploy from a branch"
4. Branch: "main" / Folder: "/ (root)"
5. Click Save. Your page is live!

✓ The client-side mirror automatically kicks in for static visitors without a Python server!

Option B: Local Zero-Dependency Server

Launch the built-in HTTP server instantly without installing third-party frameworks:

# Start server on http://localhost:8080
python -m backend.server

# Or customize port:
python -c "from backend.server import start_server; start_server(9000).serve_forever()"

Option C: PyTorch & NLLB-200 Setup

Enable full GPU neural translation using Meta's Seq2Seq model:

pip install torch transformers sentencepiece indic-nlp-library

# The backend auto-detects PyTorch
# and automatically mounts facebook/nllb-200-distilled-600M
